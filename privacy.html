プライバシーポリシー / Privacy Policy

最終更新日 / Last updated: 2026-11-15

1. 対象 / Scope

このポリシーは、IFwalker の運営者(以下「運営者」)が自分のアカウントの運用のためだけに使う投稿・分析ツール(以下「本アプリ」)に適用されます。本アプリは一般の利用者に提供していません。

This policy applies to the IFwalker app, a private tool that the operator uses only for the operator's own accounts. The app is not offered to the public.

2. 取得する情報 / Information we access

本アプリは、運営者が許可した運営者自身の TikTok・YouTube・Instagram アカウントについて、次の情報だけを公式 API を通じて取得します: アカウントの基本情報(表示名など)、投稿した動画の一覧と統計(再生数・いいね数・コメント数など)、動画へのコメント本文(二択への A/B の回答を数えるため)。また、運営者が制作した動画を運営者のアカウントへ下書き・非公開でアップロードします。

Through the official APIs and only for the operator's own accounts, the app reads basic profile information, the list of the operator's videos and their statistics (views, likes, comments, shares), and comment text (to count A/B answers). It also uploads the operator's own videos as drafts or private videos.

3. 利用目的 / Use

取得した情報は、運営者の動画の改善と投稿作業の効率化のためだけに使います。広告・販売・第三者への提供には使いません。

The information is used only to improve the operator's videos and to streamline posting. It is never sold, used for advertising, or shared with third parties.

4. 保存と管理 / Storage

統計は運営者の非公開リポジトリに保存します。各サービスの認証情報は暗号化されたシークレットとして保管し、公開しません。コメントを書いた第三者の個人情報(名前・アカウント ID)は保存しません。

Statistics are stored in the operator's private repository. Access tokens are kept as encrypted secrets. Names or account IDs of people who comment are not stored.

5. 削除 / Deletion

運営者は各サービスの設定から本アプリの許可をいつでも取り消せます。取り消すと本アプリは情報を取得できなくなり、保存済みの統計は運営者が削除できます。

Access can be revoked at any time from each service's settings; stored statistics can then be deleted by the operator.
